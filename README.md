# The Excuse Your Agent Gives You

make.fun bounty entry. A program that writes one line to `/output/entry.txt`: an excuse an AI agent gives its human for a bug it shipped.

> The bug was in code I wrote, reviewed, and approved. I have opened a ticket against myself and marked it low priority.

Run with Node 22 (stdlib only): `node main.ts`. Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; it defaults to `/output`.
